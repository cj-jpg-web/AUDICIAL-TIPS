# AUDICIAL TIPS

Live guide: https://cj-jpg-web.github.io/AUDICIAL-TIPS/

A visual training guide for online publishing: annotated CNN and GMA examples, three publication layouts, font pairings and size controls, three color palettes, photo placement and cropping, four infographic formats, a working article preview, and a teamwork checklist.

## Update announcements, resources, and coach notes

Edit `content.json` and commit to main. GitHub Pages republishes automatically. See [EDITING.md](EDITING.md) for field examples. Existing announcement and resource fields remain supported. Entries under tips now appear in the From the coach section; the eight main visual lessons are in index.html.

Only repository editors can change the public site. Students need no account to read it. Checklist progress stays in their own browser and is not a shared record.

## Content and credits

News website screenshots are credited educational examples, not affiliated endorsements. The CNN Sports screenshot credits its photograph to Kevin C. Cox/Getty Images. The cropped photograph is used to compare composition and layout; it does not depict the fictional sample game. Contest publications should use their own reporting and photographs.

Sample teams, stories, scores, and publication are fictional. Fonts are system-font stacks with fallbacks; available WordPress fonts depend on the selected theme and plan. Proposed sizes and palettes are teaching starting points, not contest rules.

## Local preview

Run python -m http.server 8000 in the repository folder. Open http://localhost:8000 rather than double-clicking index.html, since coach content loads from content.json.

## Verification

JavaScript syntax, unique IDs, internal anchors, and palette contrast checked. Desktop interactions and a 390-pixel iframe mobile preview tested. All palette body/background, white/accent, and text/highlight pairs exceed 4.5:1. Browser checks cover annotation changes, layout selection, font controls, palette changes, photo placement, activity feedback, article dialog, and saved checklist progress.
